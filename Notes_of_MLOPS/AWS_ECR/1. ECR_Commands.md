**1. Check AWS identity**
```
aws sts get-caller-identity
```

**2. Check AWS region**
```
aws configure get region
```

**2 a . Create a new ECR Repository**

```
aws ecr create-repository \
  --repository-name customer-churn-api \
  --region ap-south-1
```

**3. List existing ECR repositories**
```
aws ecr describe-repositories \
  --region ap-south-1 \
  --query "repositories[].repositoryName" \
  --output table
```

**4. Authenticate Docker with ECR:**Login Docker to AWS ECR
```
aws ecr get-login-password --region ap-south-1 | \
docker login \
--username AWS \
--password-stdin \
121470661513.dkr.ecr.ap-south-1.amazonaws.com
```

**5. Build Docker image**
```
docker build -t customer-churn-api:v1 .
```

where
```
customer-churn-api:v1
```
is your image.


**6. Check Docker images in local**
```
docker images
```

**7. Tag image for ECR:** Creating Tag for the image
```
docker tag customer-churn-api:v1 \
121470661513.dkr.ecr.ap-south-1.amazonaws.com/mlops_practice:v1
```
where
```
121470661513.dkr.ecr.ap-south-1.amazonaws.com/mlops_practice 
```
is the ECR Repository URI

and 

```
customer-churn-api:v1
```
is your local image

**8. Push image to ECR**
```
docker push \
121470661513.dkr.ecr.ap-south-1.amazonaws.com/mlops_practice:v1
```

**9. Verify image in ECR:** List all the images in ECR
```
aws ecr list-images \
  --repository-name mlops_practice \
  --region ap-south-1
```

**10. Get detailed ECR image information:**
Detailed information about ECR Images
```
aws ecr describe-images \
  --repository-name mlops_practice \
  --region ap-south-1
```
